# Vocabulary

| Term | Meaning |
|---|---|
| bipoStudio | Fixed-layout configuration application for bipoLab controllers. |
| bipoCore | Device-side hardware/control platform and communication contract. |
| Device | A physical controller or clearly identified development mock. |
| Hardware | Device-reported inventory and types of physical controls. |
| Component | A configurable physical control or its associated LED. |\n| Trigger | An analog drum-pad sensor input that is converted into a MIDI event. |
| Configuration | Persistable controller mappings, behavior, and settings. |
| Working copy | Editable draft isolated from committed device configuration. |
| Runtime | Live values and execution state; not part of saved configuration. |
| Capability | Device-reported feature or operation supported by a model/firmware. |
| Mock | Development emulation; not a physical device or verified firmware implementation. |
| Workspace | Fixed visual representation used to select device components. |
| Inspector | Contextual panel for editing the selected component’s configuration. |
